# a4-print-infographic

Claude(claude.ai) 스킬: A4 세로 인쇄물(설문지·안내문·인포그래픽)을 Design 캔버스에서 만들 때, **인쇄·PDF·큰 글자 기기에서 아래가 잘리지 않도록** 하는 규칙과 자동 맞춤 코드를 담았습니다.

## 주요 내용
- A4 794×1123px 고정 규격과 여러 장 구성
- 큰 글자 설정(+25~35%)과 웹폰트 지연 로드에도 잘리지 않는 자동 축소 래퍼
- Playwright로 1.0배 / 1.3배 높이 측정 후 게시
- 한글 줄바꿈(keep-all), 라벨 칩 정렬, 설문지·안내문 구성 규칙

## 설치
1. 이 저장소의 `a4-print-infographic` 폴더를 zip으로 압축합니다.
2. claude.ai → 사용자 지정 → Skills → 추가 → zip 업로드.
3. `SKILL.md`의 **브랜드 설정** 표를 자기 이름·연락처·디자인 시스템으로 채웁니다.
